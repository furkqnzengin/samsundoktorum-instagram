# Samsun Doktorum – Instagram otomatik paylaşım

@samsundoktorum hesabında her gün 1 story (~10:00) ve 1 post (~12:00) paylaşılır.

- `plan.json`: post sırası, açıklamalar ve story takvimi
- `publish.py`: paylaşım betiği (`python3 publish.py status|post|story [--dry]`)
- `*.jpg`: görseller (Instagram bunları bu herkese açık adresten çeker)

Erişim anahtarı bu depoda değildir; Claude ortamının ağ ayarlarında (graph.facebook.com) saklıdır.
